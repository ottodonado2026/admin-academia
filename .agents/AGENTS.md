# Reglas de Despliegue (Deployment Rules)

- Al finalizar de implementar una mejora o corrección en el código, **siempre se deben subir los cambios automáticamente a Github** (`git push`) para que Vercel inicie el despliegue automático. No se debe esperar a que el usuario lo pida explícitamente.
- **Siempre se deben colocar nombres (mensajes de commit) diferentes y descriptivos** para cada subida de cambios (ej. `Fix: ...`, `Feat: ...`, `Update: ...`). No repitas el mismo mensaje de commit.
